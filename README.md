# Mus Markagailua

Aplicación desarrollada en React Native para llevar el tanteo del juego de cartas **Mus**.

[![Descárgalo en Google Play](https://play.google.com/intl/en_us/badges/static/images/badges/en_badge_web_generic.png)](https://play.google.com/store/apps/details?id=com.musmarkagailua)

## El Problema
En las partidas improvisadas de Mus, a menudo nos encontramos sin tantos para llevar la cuenta. Esta app soluciona ese problema logístico, permitiendo jugar en cualquier lugar simplemente usando el móvil.

## Tecnologías
* **Framework:** React Native
* **Lenguaje:** TypeScript
* **Plataforma:** Android (Publicada en Play Store)
